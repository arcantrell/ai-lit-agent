# Portfolio Positioning

AI Literature Agent is intended to be the first repository in a cohesive scientific-computing portfolio.

## Core Message

This project demonstrates an experimental biologist building practical AI-assisted software for scientific workflows.

The goal is not to present the author as a generalist software engineer. The goal is to show that domain expertise in biochemistry, molecular biology, metabolomics, and research practice can guide the design of useful computational tools.

The product niche is personal literature monitoring. Broad discovery tools can map citation networks and help researchers explore fields; this project focuses on recurring PubMed surveillance, local PDF handling, editable citation metadata, and update briefs that help a scientist decide what to read next.

## Why This Project Matters

Keeping up with literature is a real bottleneck in science. Researchers often need to monitor overlapping concepts, model systems, methods, and disease contexts. This tool turns that recurring task into a reusable workflow:

- define search terms once
- search across scholarly sources
- save and tag papers
- import PDFs
- extract searchable full text
- generate an agent-style update brief

## What It Demonstrates

- Research workflow design
- Python application development
- Local data storage with SQLite
- Scholarly metadata retrieval
- PDF text extraction
- Citation export
- Agentic task orchestration
- Human-centered tooling for scientists

## Suggested Portfolio Sequence

1. AI Literature Agent
2. RNA-seq Explorer
3. Metabolomics QC Toolkit
4. Scientific Figure Generator

Together, these projects tell a coherent story: using AI and software to make biological research faster, more reproducible, and easier to interpret.

## Talking Points

- This is a tool designed from direct research pain points, not a generic demo.
- It is intentionally positioned as a focused monitoring assistant rather than a clone of broad literature-mapping platforms.
- The project is intentionally local-first so private notes and PDFs stay on the user's machine.
- External AI can be added selectively for synthesis and summarization.
- The architecture separates providers, storage, summarization, PDF handling, and agent workflows so the system can grow over time.
