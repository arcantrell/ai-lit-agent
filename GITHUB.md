# GitHub Publishing Notes

Before publishing this repository, complete these steps:

1. Choose a license.
2. Add screenshots or a short screen recording.
3. Confirm no private PDFs, notes, database files, or API keys are committed.
4. Run the test suite.
5. Create a concise repository description.

Suggested repository description:

```text
AI-assisted literature workspace for searching, saving, categorizing, and monitoring scientific papers.
```

Suggested topics:

```text
literature-review, pubmed, crossref, scientific-computing, ai-agent, biochemistry, research-tools
```

## Privacy Notes

The `.gitignore` file excludes the local database and uploaded PDFs:

```text
data/
```

Keep it that way for public repositories. The code can be public while your personal paper library remains private.
